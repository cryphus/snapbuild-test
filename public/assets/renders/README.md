# 3D-рендеры для блока «Кейсы использования»

Сюда кладутся рендеры, которые показываются в превью справа от списка ролей.
Имена файлов заданы в `src/data/newSections.ts` (поле `render` у каждого кейса):

| Кейс | Файл |
|---|---|
| Маркетинг — «Лендинг под кампанию» | `case-marketing.webp` |
| Дизайн — «В вашей дизайн-системе» | `case-design.webp` |
| Продажи — «Презентация из запроса» | `case-sales.webp` |
| Продукт — «Экспорт в нужном формате» | `case-product.webp` |

Требования к файлам:

- формат `webp` (или замените расширение в `newSections.ts` на своё);
- пропорции близкие к **4:3** — область превью подстраивается по высоте,
  изображение вписывается через `object-fit: cover`;
- фон рендера лучше делать прозрачным или в тон градиента кейса —
  подложка под изображением остаётся видимой по краям.

Пока файла нет, превью показывает штриховую подложку из макета.
Картинка подхватится автоматически, как только файл появится в этой папке —
править код не нужно.
