# снэпбилд — тестовое задание Fullstack Developer

Расширение продуктового лендинга [snapbuild.ru](https://snapbuild.ru/) пятью новыми секциями
с сохранением визуального языка исходного сайта. Выполнено по расширенному варианту задания:
существующие секции (шапка → подвал) воспроизведены самостоятельно, новые блоки встроены
между ними в логичных местах.

## 1. Что сделано

- Воспроизведена вся структура исходного лендинга: шапка со sticky-навигацией и мобильным меню,
  hero, полоса логотипов, блок «Одна платформа — весь маркетинг», табы с демо-контентом по
  типам материалов, сравнительная таблица, безопасность, горизонтальная лента роадмапа,
  FAQ-аккордеон, финальный CTA и подвал.
- Добавлено пять новых секций (см. раздел 5), органично встроенных между существующими блоками.
- Собрана единая последовательная страница — без выделения новых блоков в отдельный экран.
- Проверена адаптивность на 375 / 768 / 1280 px, отсутствие горизонтального скролла и работа
  всех интерактивных элементов.

## 2. Опубликованная версия

**https://cryphus.github.io/snapbuild-test/**

## 3. Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Приложение поднимется на `http://localhost:5173`.

Сборка продакшен-версии:

```bash
npm run build
npm run preview
```

## 4. Стек

- **Vite + React + TypeScript** — статическая сборка без бэкенда, удобна для публикации на
  GitHub Pages.
- Чистый CSS с переменными дизайн-системы (без Tailwind/UI-kit — чтобы не тянуть чужой
  визуальный язык поверх стиля снэпбилда).
- Шрифт **Manrope** (Google Fonts) — открытый аналог платного `TT Commons Pro`, используемого
  на оригинальном сайте.
- Деплой — GitHub Actions → GitHub Pages (`.github/workflows/deploy.yml`).

Структура проекта:

```
src/
  components/
    layout/     — Header, Footer
    sections/   — все секции лендинга (существующие и новые)
  data/
    siteContent.ts  — тексты и контент воспроизведённых секций сайта
    newSections.ts   — контент пяти новых секций
  styles/
    tokens.css   — переменные дизайн-системы, снятые с исходного сайта
    global.css   — базовая типографика, контейнер, кнопки, карточки
```

## 5. Пять новых секций

| Секция | Расположение | Интерактивность |
|---|---|---|
| **Кейсы использования** | после табов с демо-контентом (`#use-cases`) | — |
| **Тарифы** | после сравнительной таблицы, перед «Безопасность» | переключатель «Ежемесячно / Ежегодно» |
| **Интеграции** | после «Безопасность», перед роадмапом | — |
| **Отзывы клиентов** | после роадмапа, перед FAQ | карусель с навигацией стрелками и точками |
| **Форма заявки** | перед финальным CTA | клиентская валидация, состояние успешной отправки |

Тексты всех секций — по продукту снэпбилда (дизайн-система, маркетинговые материалы, AI),
без Lorem Ipsum.

## 6. Как анализировалась стилистика исходного сайта

Вместо визуальной оценки на глаз стили сняты напрямую из `computed styles` и CSS custom
properties боевого сайта (через DevTools/скрипты в браузере):

- **Типографика**: шрифт (`TT Commons Pro`), размеры и начертания h1–h6, letter-spacing,
  line-height для заголовков, текста и мелких лейблов.
- **Цвета**: фон страницы (`#f5f5f6`) и единственной секции с белым фоном (финальный CTA),
  нейтральная шкала (100–900), цвет текста и приглушённого текста, цвет разделителей.
- **Компоненты**: у сайта обнаружена собственная дизайн-система на ~500 CSS-переменных
  (`--card-*`, `--btn-*`, `--input-*`, `--chip-*`, `--tab-*`, `--accordion-*` и т.д.) — из неё
  взяты радиусы карточек (24px), кнопок (12px), инпутов (20px), толщина и цвет границ.
- **Сетка и отступы**: grid-gap карточек, вертикальные паддинги секций, ширина контейнера.
  Ориентировочные значения зафиксированы в `src/styles/tokens.css`.
- **Брейкпоинты**: найдены непосредственно в CSS сайта (767 / 768–1023 / 1024px) — совпадают с
  ориентирами ТЗ (375 / 768 / 1280).

Полный протокол анализа — в [`PLAN.md`](./PLAN.md), раздел 1.

## 7. Что удалось воспроизвести из исходной страницы

Все текстовые секции лендинга воспроизведены 1:1 по структуре и контенту: шапка, hero, полоса
логотипов, «Одна платформа — весь маркетинг», табы с демо-фичами по 5 типам контента,
сравнительная таблица (снэпбилд vs конкуренты), безопасность, полный роадмап из 11 карточек
(декабрь 2025 — ноябрь 2026), все 8 вопросов FAQ, финальный CTA и подвал с навигацией и
контактами.

Не воспроизводились: фоновые декоративные изображения/иллюстрации исходного сайта (сайт
использует минимум графики за пределами текста и иконок) и анимации на скролле — визуальный
эффект от них второстепенен по сравнению со структурой и типографикой.

## 8. Что не удалось реализовать и почему

- Точный шрифт `TT Commons Pro` — платный, не распространяется публично. Заменён на близкий по
  пропорциям Manrope с пояснением в токенах.
- Логотипы клиентов в полосе доверия — на исходном сайте это, вероятно, реальные логотипы
  партнёров; в копии они переданы текстовыми названиями в едином начертании, чтобы не
  использовать чужие товарные знаки без разрешения.
- Тонкие детали анимаций/transition при скролле (сайт использует `cubic-bezier(0.16, 1, 0.3, 1)`
  для входа элементов) — перенесён только сам ease-токен, полноценные scroll-triggered анимации
  не реализовывались из-за ограничения по времени.

## 9. Что бы улучшил при наличии дополнительного времени

- Добавил бы `prefers-reduced-motion`-совместимые анимации появления секций при скролле,
  как на оригинальном сайте.
- Провёл бы более точный аудит контраста и focus-состояний по всем интерактивным элементам
  (кастомные фокус-стили сейчас есть только у кнопок).
- Заменил бы текстовые заглушки логотипов клиентов и иконок интеграций на подготовленные SVG.
- Написал бы unit-тесты на валидацию формы и переключатель тарифов.

## 10. Использованные AI-инструменты

- **Claude (Anthropic)** — анализ ТЗ, снятие визуальных токенов исходного сайта через
  автоматизированный браузер (computed styles, CSS custom properties, брейкпоинты), генерация
  React-компонентов и контента секций, отладка, проверка сборки и адаптивности, настройка
  GitHub Actions деплоя. Весь сгенерированный код проверен вручную: интерактивность каждой
  секции (табы, аккордеон, карусель, форма, переключатель тарифов) протестирована в браузере,
  проверены отсутствие горизонтального скролла на трёх ширинах и контраст текста.
