# План: Fullstack Developer — тестовое задание (снэпбилд)

Отслеживаем прогресс галочками. Обновлять статус по мере выполнения.

## 0. Контекст задания

- Задача: продолжить лендинг [snapbuild.ru](https://snapbuild.ru/) пятью новыми секциями так,
  чтобы они выглядели органичной частью сайта, а не вставкой из другого шаблона.
- Сдача: публичный GitHub-репозиторий + публикация на GitHub Pages
  (`username.github.io/project-name`).
- Делаем **расширенный** вариант: самостоятельно воспроизводим существующие секции сайта
  (шапка → подвал) и встраиваем 5 новых секций между ними в логичных местах.
- Оценивается прежде всего соответствие дизайну и аккуратность продолжения интерфейса, а не
  объём кода.

### 1.1 Структура секций сайта (сверху вниз)

1. Header — лого + меню (`Продукт`, `Возможности`, `Безопасность`, `FAQ`) + CTA «Начать сейчас»,
   мобильное меню отдельно
2. Hero — заголовок, подзаголовок, CTA
3. Полоса логотипов клиентов («С платформой работают команды…»)
4. «Одна платформа — весь маркетинг» — 3 карточки-фичи (article), grid 3 колонки
5. Табы по типу контента (Сайты / Изображения / Видео / Баннеры / Презентации) — демо-фичи под
   каждым табом
6. Сравнительная таблица «Почему команды выбирают Снэпбилд» (снэпбилд vs конкуренты)
7. «Безопасность без компромиссов» — 3 карточки
8. Roadmap — 11 карточек по месяцам (Дек 2025 → Ноя 2026)
9. FAQ — аккордеон, 8 вопросов
10. Финальный CTA (белый фон — единственная секция с `#ffffff`, остальные `#f5f5f6`)
11. Footer — лого, навигация, документация, контакты (Telegram/email)

### 1.2 Токены дизайн-системы (сняты из computed styles / CSS custom properties)

**Шрифт и типографика**
- Шрифт: `"TT Commons Pro", sans-serif` (платный шрифт — для копии подобрать близкий бесплатный
  аналог, например `Manrope`/`Inter`, зафиксировать это решение в README)
- Body: 16px / 400 / line-height 1.5
- H1: ~67.5px desktop / вес 600–700 / line-height 1.15 / letter-spacing -0.01em… -0.04em (hero)
- H2: ~46px / вес 500–700 / line-height 1.15 / letter-spacing -0.01em
- H3–H6: вес 600, line-height 1.2–1.3
- Текст-лид (подзаголовки): цвет `--color-neutral-500`, вес 400
- Мелкий/подпись текст: цвет `--color-neutral-400`

**Цвета**
- Фон страницы / большинства секций: `#f5f5f6` (`--color-background`)
- Фон финальной CTA-секции: `#ffffff`
- Фон карточек: `#fdfdfd`, граница карточек: `--color-neutral-200` (`#F2F2F4`), радиус `24px`,
  ширина границы `1px`
- Neutral-шкала: 100 `#FFFFFF` → 200 `#F2F2F4` → 300 `#E5E5E7` → 400…900 через `oklch`
  (от светло-серого до почти чёрного)
- Текст основной: `#000000` / `--text-primary`
- Текст вторичный: `#5A5B62` (`--text-secondary`), третичный: `rgba(0,0,0,0.6)`
- Разделители: `rgba(0,0,0,0.08)` (`--divider-color`), `stroke-tertiary: rgba(0,0,0,0.1)`
- Акцентный (primary-500) в дизайн-системе — `#ffffff`/переопределён, фактический «акцент» на
  сайте — чёрно-белый монохром (никаких ярких цветов), primary-палитра с синим (`#5e84fc`,
  `#1c1c1f` и т.д.) в CSS есть, но визуально на лендинге не используется — вывод: сайт сознательно
  чёрно-белый, без цветных акцентов
- Оверлеи: `--overlay-dark: #00000080`, `--overlay-light: rgba(255,255,255,0.9)`

**Кнопки**
- Основная (`btn` / чёрная): фон `#000000` (`--color-neutral-800/900`), текст `#fff`, радиус
  `12px`, padding `10px 20px`, font-size 14px, weight 600, letter-spacing -0.5px
- Outline-кнопка: прозрачный фон, граница `1.5px solid var(--color-neutral-300)`, радиус как у
  primary
- Hover: `--btn-bg-hover: var(--color-neutral-900)` — слегка темнее/чернее

**Карточки / чипы / табы / аккордеон**
- Card: радиус `24px`, фон `#fdfdfd`, граница `1px solid #F2F2F4`, без тени (`shadow: none`)
- Chip: радиус `50px` (пилюля), padding-block `6px`, граница `1px solid #252525`
- Tab: высота `3rem`, радиус `999px` (пилюля), граница `1px`, активный цвет через primary
- Accordion (FAQ): без своей карточки-фона, разделитель между пунктами `1px solid
  var(--color-neutral-200)`, radius `var(--radius-md)` при варианте card

**Инпуты (для формы)**
- Радиус `20px`, фон `--color-neutral` (белый), граница `1px solid --color-neutral-300`,
  плейсхолдер `--color-neutral-500`, фокус — граница `--color-primary-400`

**Сетка / отступы**
- Grid трёх карточек (feature-блок): `display: grid`, `gap: 28.4px`, колонки ~`384px / 376px /
  376px` на desktop 1280
- Вертикальные отступы секций: paddingTop ~28px, paddingBottom 85–114px (крупные секции),
  финальный CTA — 128px сверху/снизу, футер — ~57px
- Motion: `--motion-ease: cubic-bezier(0.16, 1, 0.3, 1)`, уважает `prefers-reduced-motion`

**Брейкпоинты (обнаружены в CSS сайта)**
- `max-width: 767px` — mobile
- `min-width: 768px` / `min-width: 768px and max-width: 1023px` — tablet
- `min-width: 1024px` — desktop
- `min-width: 1440px and max-width: 2559.98px`, `min-width: 2560px` — большие экраны
- ⇒ ориентироваться на mobile ≤767, tablet 768–1023, desktop ≥1024 (совпадает с требованиями ТЗ:
  375 / 768 / 1280)
